# Crypto Portfolio Lab

An interactive research dashboard for our QF600 Asset Pricing group project at Singapore Management University.

## Live dashboard

https://yuhong-xiao.github.io/qf600-crypto-portfolio-lab/

## Research question

Can portfolio stabilisation overcome noisy expected-return estimates in a correlated crypto universe?

## What the project covers

- BTC-correlation universe screening
- Crypto market and momentum factors
- Mean-variance optimisation
- Ridge and cost-aware stabilisation
- Rolling out-of-sample backtesting with trading costs

## Key result

Equal weighting achieved the strongest out-of-sample result in this sample. More stable optimisation methods reduced portfolio instability, but did not necessarily improve realised performance.

This repository contains a redesigned interactive presentation of a QF600 Group 6 academic project. Data source: Yahoo Finance, 2018–2026. For research and educational purposes only; not investment advice.
